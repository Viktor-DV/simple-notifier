## Тексты для карточки RuStore

### Название (≤30 символов)

**Простые напоминания**

### Краткое описание (≤80 символов)

Локальные напоминания с уведомлением в выбранную дату и время. Без регистрации.

### Полное описание

**Простые напоминания** — приложение для личных напоминаний на телефоне. Все данные хранятся только у вас на устройстве, интернет для работы не нужен.

**Возможности:**
- напоминания с заголовком и датой;
- уведомление в выбранный день и время (своё или по умолчанию из настроек);
- категории и фильтр по ним;
- поиск по названию;
- сортировка по дате (ближайшие или поздние);
- фото к напоминанию (если фото нет — в списке и в уведомлении показывается иконка приложения);
- русский и английский интерфейс;
- светлая и тёмная тема.

**Уведомления:** разрешите уведомления и при необходимости точные будильники в настройках Android. В приложении: «Настройки» → «Проверить разрешение на уведомления».

**Что нового? (первая версия)**

Первый выпуск: напоминания, категории, уведомления, поиск, сортировка, фото, RU/EN, тёмная тема.

### Контакты

Укажите email поддержки (обязательно хотя бы один контакт).

### Безопасность данных (декларация)

- данные хранятся **локально** на устройстве;
- **уведомления** — для напоминаний в заданное время;
- **фото** — только если пользователь сам добавил к напоминанию (доступ к галерее);
- **точные будильники** — для своевременных уведомлений на части устройств;
- персональные данные на сервер **не передаются** (если не добавите аналитику позже).

## Подпись APK

Сейчас release собран с **debug-подписью**. Для всех обновлений в RuStore нужен **один и тот же release-keystore**. Перед финальной публикацией создайте keystore и пропишите signing в `android/app/build.gradle.kts`.
